# Building HF Gambling Suite

These steps rebuild the extension exactly as it's published.

## Requirements

- Node.js 22 or newer and npm 10
- Any operating system (Windows, macOS or Linux)

## Build

```bash
npm ci
npm run build
```

`dist/` then holds the built extension. `background.js`, `content.js`, `page-bridge.js` and `options.js` are bundled and minified by webpack from the TypeScript in `src/` (configuration in `config/`). `manifest.json`, `options.html`, `options.css` and the icons in `src/assets/` are copied from `src/` unchanged. The blackjack strategy table (`src/games/blackjack/strategyTable.json`) is generated by `scripts/generate-strategy-table.js` and committed; `npm run strategy:generate` recreates it identically.

The Firefox package's `manifest.json` is `src/manifest.json` with the Firefox-only keys added by `scripts/firefox-manifest.js`: `browser_specific_settings`, and `background.scripts` in place of `background.service_worker`.

## Release packages

```bash
npm run package
```

This builds, then writes three zips to `releases/`:

- `hfgs-<version>-chrome.zip`: for the Chrome Web Store
- `hfgs-<version>-firefox.zip`: for Firefox Add-ons
- `hfgs-<version>-firefox-source.zip`: this source, for Firefox Add-ons' review

The packager checks that `src/manifest.json` and `package.json` have the same version and that every file the manifest names is in the build.

## Trying the Firefox build

In Firefox, open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, and pick `manifest.json` inside an unzipped `hfgs-<version>-firefox.zip`. Or run `npm run browser:firefox`.

## Checks

```bash
npm run typecheck
npm test
npm run lint
```
